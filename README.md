# SAKINFAN.COM

The official code for sakinfan.com.  
The website uses Jinja2 templates and server rendered HTML to run. The backend uses FastAPI, the DB is postgreSQL.  
I built the website with around 100 concurrent users in mind.  

The frontend is a copy I found from internetarchive of the original site, that seems to have went down at 2009.  
Feel free to fork and open a pull request for any improvements.
